## 主要功能模块

### 1. 数据获取模块 (data_loader.py)
- **功能**: 从 AkShare 获取美股日线数据
- **支持的股票代码**: 单个股票代码（如 AAPL, TSLA）和指数代码（如 .IXIC, .DJI）
- **数据缓存**: 支持数据本地缓存，提高数据获取效率
- **数据格式**: 标准化的 Pandas DataFrame，包含日期、开盘价、最高价、最低价、收盘价、成交量等字段

### 2. 因子计算模块 (factor_engine.py)
- **宏观风险因子**:
  - 流动性因子 (liquidity_factor)
  - 波动率期限结构 (volatility_term_structure)
  - 信用利差代理 (credit_spread_proxy)
  - 通胀率代理 (inflation_rate_proxy)

- **中性因子**:
  - Beta 中性 (beta_neutral)
  - 行业中性 (sector_neutrality)
  - 市值中性 (size_neutrality)

- **风险预警与防御因子**:
  - 拥挤度因子 (crowding_factor)
  - 贝叶斯收缩 (bayesian_shrinkage)
  - 动态动能反转 (dynamic_momentum_reversal)

- **因子计算特点**:
  - 向量化计算，提高计算效率
  - 支持自定义窗口参数
  - 自动处理极值和标准化

### 3. 回测引擎模块 (backtest_engine.py)
- **回测类型**: 向量化回测
- **支持的信号类型**: 基于因子加权的组合信号
- **手续费计算**: 支持自定义手续费率
- **仓位管理**: 支持满仓操作
- **性能指标**:
  - 累计收益率
  - 年化收益率
  - 年化波动率
  - 夏普比率
  - 最大回撤

- **因子权重优化**:
  - 使用 Scipy.optimize.minimize 进行权重优化
  - 目标函数：平衡夏普比率和风险
  - 支持风险厌恶系数调整
  - 约束条件：权重和为1，权重非负

### 4. 应用界面模块 (app.py)
- **界面框架**: Streamlit
- **主要功能**:
  - 股票代码输入
  - 日期范围选择
  - 初始资金和手续费设置
  - 因子组合配置（支持1-3种因子组合）
  - 因子权重调整
  - 一键优化因子权重
  - 回测结果展示
  - 交易记录可视化
  - 净值曲线绘制

- **界面特点**:
  - 响应式设计，适配不同屏幕尺寸
  - 直观的因子选择界面
  - 实时的回测结果展示
  - 支持中文显示

## 使用说明

### 环境搭建
```bash
# 安装依赖
pip3 install streamlit pandas numpy plotly scipy akshare

# 运行应用
python3 -m streamlit run app.py
```

### 基本操作
1. 在左侧侧边栏配置参数
2. 选择1-3种宏观风险因子、中性因子和风险预警因子
3. 调整风险厌恶系数（可选）
4. 点击"运行回测"或"一键优化"
5. 在右侧查看回测结果

### 因子配置建议
- **宏观风险因子**: 建议选择流动性因子和波动率期限结构
- **中性因子**: 建议选择Beta中性
- **风险预警因子**: 建议选择拥挤度因子

## 开发过程中的主要问题及解决方案

1. **AkShare API 兼容性问题**
   - 问题: 调用 `stock_us_daily()` 时使用了已废弃的 `symbol_kind` 参数
   - 解决方案: 移除了该参数，使用最新的API格式

2. **因子选择数量验证**
   - 问题: 用户可能选择过多或过少的因子
   - 解决方案: 添加了验证逻辑，确保每个类别选择1-3种因子

3. **日期选择器显示英文月份**
   - 问题: Streamlit 日期选择器默认显示英文月份
   - 解决方案: 使用了自定义的日期选择方式，确保月份显示为数字

4. **Streamlit locale 参数不支持**
   - 问题: 尝试使用 `locale='zh'` 参数时出现错误
   - 解决方案: 移除了该参数，使用默认配置

5. **优化算法性能问题**
   - 问题: 因子权重优化过程较慢
   - 解决方案: 使用了高效的优化算法，并限制了优化次数
