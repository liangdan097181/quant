# 美股量化回测系统

基于 AkShare 数据源的轻量级量化分析工具，支持因子策略回测和权重优化。

## 项目简介

该项目是一个用于美股量化回测的系统，支持多因子策略配置和权重优化。用户可以通过直观的Web界面配置各种策略参数，查看回测结果和交易记录。

## 主要功能

- **数据获取**：从 AkShare 获取美股日线数据，支持单个股票和指数
- **多因子策略**：支持宏观风险因子、中性因子、风险预警因子的组合配置
- **因子权重优化**：基于夏普比率和风险厌恶系数的一键权重优化
- **详细回测报告**：包含累计收益率、年化收益率、夏普比率、最大回撤等指标
- **交易记录可视化**：显示每笔交易的买入/卖出时间、价格、股数和收益率
- **净值曲线绘制**：对比策略表现与基准指数

## 技术栈

- **Python 3.9+**：开发语言

## 使用说明

### 基本操作

1. **配置参数**：在左侧侧边栏配置股票代码、日期范围、初始资金等参数
2. **选择因子**：从宏观风险因子、中性因子、风险预警因子中各选择1-3种因子
3. **调整权重**：调整各因子的权重（可选）
4. **优化权重**：点击"一键优化"按钮自动优化因子权重
5. **运行回测**：点击"运行回测"按钮开始回测
6. **查看结果**：在右侧查看回测结果、交易记录和净值曲线

### 因子配置建议

- **宏观风险因子**：建议选择流动性因子和波动率期限结构
- **中性因子**：建议选择Beta中性
- **风险预警因子**：建议选择拥挤度因子

### 风险厌恶系数

- **值越小**：越激进，追求高收益
- **值越大**：越保守，注重风险控制
- **建议范围**：0.1-3.0
